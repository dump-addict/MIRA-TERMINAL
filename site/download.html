Homebrew

On a Mac, install and update Mira from the terminal.

brew install --cask dump-addict/tap/mira-terminal

First launch

  • macOS. Early builds are not signed yet: right-click Mira Terminal and choose Open, once.
  • Windows. If SmartScreen warns you, choose More info, then Run anyway. Agents run in Git Bash, so install Git for Windows first.
  • Linux. Make the AppImage executable with chmod +x Mira-Terminal-linux-x64.AppImage, then run it.
  • Everywhere. At least one coding agent installed and signed in, and Python 3 for the architecture diagram.

Build from source

Node 24, pnpm 12 and Python 3.

git clone https://github.com/dump-addict/MIRA-TERMINAL.git
cd MIRA-TERMINAL
pnpm install
pnpm dev

Every release and its notes are on GitHub Releases.
