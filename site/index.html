Questions, answered.

What people ask before they install Mira: the price, their agents, their accounts and their code.

Still a question?Ask it on GitHub, we answer there.→
01Is Mira free?

Yes, and for good. Mira is open source under the MIT license, with no server, no account and nothing to sell. You only pay for the agents you choose to use, with your own subscriptions.

02Which agents does it work with?

Claude Code, Codex, Gemini CLI, Cursor, GitHub Copilot and Grok are detected and get their own logo and message box. Any other agent that runs in a terminal works in a plain tab. Mira runs the agents already installed on your computer, in their own version, and each one signs in by itself: Mira stores no password.

03Can I use several accounts of the same agent?

Yes, for Claude Code and Codex. Each account keeps its own sign-in, and you switch from one to the other in a click, with no sign-out and no sign-in again. Its usage for the day, the week and the month stays in view. When one account gets close to its limit, switch to another and keep working.

04What can the agents do on my machine?

What they can do in any terminal, nothing more. Mira asks before anything is deleted, keeps your secrets out of their reach, and lets you trust each project one by one.

05Does my code leave my machine?

Not because of Mira. The diagram, its checks and dictation run locally. Your agents talk to their own services, exactly as they do in any terminal.

06Will my terminal still work the same way?

Yes. The message box sits on top of the agent’s own input: the real terminal runs underneath, so every command, shortcut and menu works exactly as before. One click goes back to the plain terminal.

07How is the architecture diagram made?

Your agent reads the code once and writes the diagram into the project. Mira draws it, keeps it up to date and runs quick checks on each block, such as an API answering or a key being set.

08Which systems are supported?

macOS (Apple silicon and Intel), Windows 10 and 11, and Linux as an AppImage. On a Mac you can also install it with Homebrew.

09Can I contribute?

Yes. Open an issue or a pull request on GitHub. The contributing guide explains how to run Mira locally.
